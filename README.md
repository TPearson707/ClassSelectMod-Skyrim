# Class Select Mod

**Author:** Thomas  
**Version:** 1.1  
**Game:** The Elder Scrolls V: Skyrim Special Edition

---

## Description

Class Select adds an interactive button to Honeyside in Riften that allows you to choose a starting class and receive appropriate gear for that archetype. Whether you want to play as a hardened warrior, a cunning thief, a deadly assassin, or a powerful mage, this mod gives you a thematic gear set to start your adventure with.

---

## Classes

**Warrior** — Steel armor, Skyforge Steel Sword, shield, and the Amulet of Talos. The shield wall holds.

**Thief** — Thieves Guild armor, Valdr's Lucky Dagger, an enchanted hunting bow, steel arrows, and the Amulet of Articulation. From the shadows none shall find you.

**Assassin** — Dark Brotherhood armor, Friniel's End elven bow, elven arrows, and Muiri's Ring. Sithis smiles upon you.

**Mage** — Apprentice mage robes, college boots, a chain lightning staff, spell tomes for Firebolt, Lightning Bolt, and Ice Spike, an enchanted necklace and ring of magicka. May your mind prove sharper than any blade.

## Installation

1. Extract the zip file
2. Place `Class01.esp` in your Skyrim Special Edition `Data` folder
3. Place `ClassSelectButtonScript.pex` in `Data\Scripts`
4. Enable `Class01.esp` in your mod manager or launcher

---

## Usage

Travel to Honeyside in Riften. The button is located inside. Activate it and select your class. If you do not own Honeyside, use the console command `coc RiftenHoneyside` to access it.
